# Create API Workflow

1. Inspect existing ASP.NET Core API patterns.
2. Inspect the relevant model, DTO, and existing endpoint.
3. Create or update DTOs if required.
4. Add the API endpoint or filter.
5. Implement the required service/business logic.
6. Add validation.
7. Add appropriate error handling and HTTP status codes.
8. Add unit/integration tests.
9. Run the relevant tests.
10. Update documentation if required.

Follow the project's existing architecture and coding standards.
Do not modify unrelated functionality.
